# PRレビュー基準
1. **最小限の実装**: 不要な複雑性やオーバーエンジニアリングがないか。
2. **ネットワーク制約**: 通信が `localhost` (`127.0.0.1`) 前提（ホストネットワーク）になっているか。
3. **設定ファイル**: YAML設定と環境変数の扱いに矛盾がないか。
4. **自動生成ファイル**: `*.pb.go` やバイナリなどの自動生成物がレビュー対象に入っていないか。

## 注意事項
- `docs/rules`配下に保存されている*mdファイル*は手動で修正してローカルで検証済のためPRレビューの対象外とする。
- 同様に`.clinerules`もPRレビューの対象外とする。
