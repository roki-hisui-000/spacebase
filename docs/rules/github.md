# GitHub連携・Git運用規約

## ブランチ運用ルール
- **デフォルトブランチ**: `develop`
- **禁止事項**: `develop` への直接コミット・直接プッシュは**厳禁**。
- **開発フロー**:
  1. `develop` からブランチ（`feature/`、`fix/` など）を切る。
  2. 変更をコミットし、プッシュしてプルリクエスト（PR）を作成する。

## Git管理除外（.gitignoreの徹底）
以下のファイルはGit管理から除外し、誤ってコミットしないこと。
- ビルド済みバイナリ（`processing`, `server` など）
- ログファイル（`*.log`）
- 一時ファイル（CLIテスト用の一時ファイル等）

## 推奨 Git コマンドフロー
1. 状態確認: `git status`
2. ステージング: `git add .` (不要なバイナリ等が含まれていないか注意)
3. コミット: `git commit -m "feat: <内容>"`
4. プッシュ: `git push origin <branch_name>`
