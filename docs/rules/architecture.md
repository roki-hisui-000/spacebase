# アーキテクチャ・設計思想

## プロジェクト概要
- Go言語によるスペースベースアーキテクチャ（仮想ミドルウェア + Processing Unit）。
- AIエージェントは本ルールを「Skill」として理解し、開発作業を正確に実行すること。

## システム構成
- **Middleware**: HTTPリクエスト受付。内部でgRPCを用いてProcessing Unitと通信。
- **Processing Unit**: gRPCサーバー。受信データをValkey（永続化）に保存。
- **Valkey**: Redis互換インメモリデータストア。ホスト上で直接稼働 (`127.0.0.1:6379`)。

## ネットワーク・インフラ制約
- 全コンテナはホストネットワークモード (`network: host`) で動作。
- コンテナ間やValkeyへの通信はすべて `localhost` (`127.0.0.1`) 経由。独自ネットワークは使用禁止。

## 開発・行動指針
- **最小限の実装**: コード追加・リファクタは常に最小限とし、既存の互換性を維持する。
- **設定ファイル**: 環境別設定は `config/config.dev.yaml` 等で管理。環境変数との整合性に注意。
- **gRPCスキーマ変更**: `proto/processing.proto` 変更時は、必ず `make generate` 等（存在する場合）で Go コードを再生成すること。
